# Bloc package tts_dataset

## Getting started

Import package in project.

```yaml
tts_dataset_bloc: any
```

## Usage

Import bloc in provider

```dart
import 'package:tts_dataset_bloc/tts_dataset_bloc.dart';


BlocProvider<TtsDatasetBloc>(
    create: (BuildContext context) => TtsDatasetBloc(),
),

```
